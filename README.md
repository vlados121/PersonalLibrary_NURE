# Курсова робота: Особиста бібліотека

## Опис проєкту
Цей проєкт є консольним додатком на C# (.NET 8) для управління домашньою картотекою книг. Розроблено в рамках курсової роботи з дисципліни "Об'єктно-орієнтоване програмування".

## Основний функціонал
- Додавання, редагування та видалення книг.
- Пошук книг за автором або назвою.
- Відстеження статусу книги (можливість позначити, кому з друзів ви віддали книгу).
- Фільтрація книг за рейтингом (оцінкою).
- Автоматичний підрахунок загальної кількості книг у бібліотеці.
- Збереження даних: автоматичний запис та читання списку книг з файлу `library.json`.

## Як запустити
1. Переконайтеся, що на вашому комп'ютері встановлено .NET 8 SDK.
2. Відкрийте термінал у папці з проєктом.
3. Виконайте команду для запуску:
   ```bash
   dotnet run
   ```
